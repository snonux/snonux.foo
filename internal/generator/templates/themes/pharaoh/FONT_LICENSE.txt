Cinzel and Alegreya Sans
========================

This directory bundles the web fonts:

    cinzel-v26-latin-var.woff2          (variable, weights 500-800)
    alegreya-sans-v28-latin-400.woff2   (weight 400)
    alegreya-sans-v28-latin-700.woff2   (weight 700)

Subset: latin.

Source / version
----------------
- Cinzel family page        : https://fonts.google.com/specimen/Cinzel
- Cinzel designer           : Natanael Gama
- Cinzel webfont set        : cinzel-v26 (latin, woff2)
- Cinzel project            : https://github.com/NDISCOVER/Cinzel

- Alegreya Sans family page : https://fonts.google.com/specimen/Alegreya+Sans
- Alegreya Sans designer    : Juan Pablo del Peral (Huerta Tipografica)
- Alegreya Sans webfont set : alegreya-sans-v28 (latin, woff2)
- Alegreya Sans project     : https://github.com/huertatipografica/Alegreya-Sans

- Fetched via               : fonts.googleapis.com css2 API (files from fonts.gstatic.com)
- Fetched on                : 2026-10-21
