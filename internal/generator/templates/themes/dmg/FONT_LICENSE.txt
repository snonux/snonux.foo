DMG theme fonts
===============

This directory bundles the web fonts:

    press-start-2p-v16-latin-400.woff2  (Press Start 2P, weight 400)
    pixelify-sans-v3-latin-var.woff2    (Pixelify Sans, variable weight 400-600)

Subset: latin.

Source / version
----------------
- Press Start 2P family page  : https://fonts.google.com/specimen/Press+Start+2P
- Press Start 2P designer     : CodeMan38
- Press Start 2P webfont set  : press-start-2p-v16 (latin, woff2)
- Pixelify Sans family page   : https://fonts.google.com/specimen/Pixelify+Sans
- Pixelify Sans designer      : Stefie Justprince
- Pixelify Sans webfont set   : pixelify-sans-v3 (latin, variable, woff2)
- Fetched via                 : fonts.googleapis.com css2 API (files from fonts.gstatic.com)
- Fetched on                  : 2026-10-21
