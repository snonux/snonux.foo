Greenhouse theme fonts
======================

This directory bundles the web fonts:

    fraunces-v38-latin-var.woff2  (Fraunces, variable weight 400-700)
    karla-v33-latin-var.woff2     (Karla, variable weight 400-600)

Subset: latin.

Source / version
----------------
- Fraunces family page  : https://fonts.google.com/specimen/Fraunces
- Fraunces designer     : Undercase Type (Phaedra Charles, Flavia Zimbardi)
- Fraunces webfont set  : fraunces-v38 (latin, woff2)
- Fraunces fetched via  : fonts.googleapis.com css2 API
- Karla family page     : https://fonts.google.com/specimen/Karla
- Karla designer        : Jonathan Pinhorn
- Karla webfont set     : karla-v33 (latin, woff2)
- Karla fetched via     : fonts.googleapis.com css2 API
- Fetched on            : 2026-10-21
